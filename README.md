Imagina que el lector RFID (tu placa YRM1004) es un profesor en un salón oscuro con una linterna muy potente (la antena), y los tiquets (Tags) son estudiantes con pequeños espejos.La Interrogación (Energía): El lector enciende su linterna y baña la habitación con ondas de radio.La Respuesta (Retrodifusión): Los tags pasivos no tienen batería. Cuando la onda los golpea (la luz al espejo), la antena del tag absorbe esa energía, enciende un microchip diminuto por un milisegundo, y altera la forma en que rebota la señal, enviando su código EPC.El Resultado: El lector capta ese rebote modificado y lo traduce en números legibles por nuestro ESP32.A este fenómeno se le conoce como Retrodifusión Modulada (Modulated Backscatter).📻 Frecuencias y Tecnologías SimilaresTecnologíaFrecuenciaRango de LecturaCaracterísticas / DiferenciasLF (Low Frequency)125 - 134 kHzContacto a 10 cmLento, no lee múltiples tags a la vez. HIGH = Encendido, LOW = Apagado.⚠️ Consideraciones Críticas para SIM7000G / SIM7070GIntegrar celular IoT y RFID UHF en un solo sistema requiere cuidados especiales:1. Gestión de Puertos Seriales (UART Conflictos)El ESP32 tiene 3 puertos UART por hardware. Debes asignarlos correctamente para que no "choquen":Serial0: Reservado para la conexión USB y el Monitor Serial de la PC.Serial1: Usualmente mapeado internamente para comunicarse con el módem SIM7000G/SIM7070G (comandos AT).Serial2: ¡Este es el que debes usar para el YRM1004! Mapea HardwareSerial(2) a pines libres que no interfieran con la SIM, el GPS o la tarjeta SD (por ejemplo, pines 13, 14, 25, 26, dependiendo de tu modelo específico de placa).2. El "Apocalipsis" de la Energía (Picos Combinados)El YRM1004 pide picos de ~1A al leer.El SIM7000G/7070G pide picos de hasta 2A al registrarse en la red celular LTE.Si ambos ocurren a la vez, el sistema exige 3 Amperios. Un Arduino UNO suele entregar máximo 500mA - 800mA.Recomendación: Si el ESP32 se reinicia constantemente, el Arduino no es suficiente. Reemplázalo por una fuente externa de 5V y 3A (o un convertidor DC-DC LM2596), manteniendo siempre el GND compartido.3. Interferencia de Radiofrecuencia (EMI)El RFID UHF opera entre 860-960 MHz. Las bandas LTE (como la Banda 8 o la Banda 20) de los módulos SIM70xx operan en frecuencias extremadamente cercanas (900 MHz / 800 MHz).Solución: Mantén físicamente separadas la antena del SIM7000G (la antenita negra plana o de varilla) y la placa verde de la antena del YRM1004. Nunca las pongas una encima de la otra, o la lectura del RFID será pobre y el módem celular perderá señal.💻 Lógica de CódigoEl flujo del código debe considerar la inicialización de dos periféricos simultáneos:#include <HardwareSerial.h>

// Definir Serial1 para SIM7000G (Normalmente predefinido en placas LilyGO)
#define SIM_TX_PIN 27 
#define SIM_RX_PIN 26

// Definir Serial2 para el Lector RFID YRM1004
HardwareSerial rfidSerial(2); 
#define RFID_RX_PIN 13 // Pin libre elegido
#define RFID_TX_PIN 14 // Pin libre elegido

void setup() {
  Serial.begin(115200); // PC / Debugging
  
  // Iniciar SIM7000G
  Serial1.begin(115200, SERIAL_8N1, SIM_RX_PIN, SIM_TX_PIN);
  
  // Iniciar RFID YRM1004
  rfidSerial.begin(115200, SERIAL_8N1, RFID_RX_PIN, RFID_TX_PIN);

  // Pin EN del RFID
  pinMode(4, OUTPUT);
  digitalWrite(4, HIGH); // Despertar lector
}
🚨 Consideraciones en Caso de Fallas (Troubleshooting)El Síndrome de la Tierra Ausente (GND):Síntoma: Datos corruptos en el monitor serial o el módulo no responde.Solución: Asegúrate de que el GND de la fuente externa y el GND de la placa LilyGO/ESP32 estén interconectados.Fallo por Caída de Tensión (Brownout Detect):Síntoma: El ESP32 arroja un error de "Brownout" en el monitor serial o se reinicia al subir datos a la nube o leer un tag.Solución: Falta de amperaje. El Arduino UNO no está soportando el módem celular y el RFID al mismo tiempo. Pasa a una fuente externa dedicada de mayor amperaje.Módulo "Muerto" (El pin EN):Síntoma: Absolutamente nada ocurre en la lectura de tags.Solución: Verifica con un multímetro que el pin EN está recibiendo voltaje. Si está desconectado, el chip lector está en estado de suspensión (Sleep Mode).Cables TX/RX Invertidos:Síntoma: No hay comunicación con el RFID.Solución: Cruza los cables. El TX del ESP va al RX del lector, y viceversa.Polarización y Materiales Cerca de la Antena:Síntoma: El tag solo lee a 5 cm.Solución: Los tags UHF odian el metal y el agua. No sostengas el tag cubriendo la antena con tu mano. Aléjalo de la antena celular del SIM7000G.
